# Проверка локального запуска и форматирования интерфейса

Основа проверки: `master` `77d5431`. Проверялись действующий интерфейс Stemma, его состояния и общие компоненты; существующие Base UI/shadcn (`base-nova`), Tailwind v4 и Recharts сохранены.

## Ошибка локальной базы

Ошибка со скриншота воспроизведена на локальной `qc_app`: отсутствовала колонка `Review.calibrationSessionId`. Не были применены три уже существующие миграции: `20261006110000_calibration_review_session`, `20261006113000_allow_out_of_sample`, `20261007120000_backfill_calibration_review_session`.

Перед применением сохранена закрытая резервная копия `/tmp/stemma-qc-app-before-migration-20261013.dump`. Применены именно существующие миграции, без reset или повторного seed. Проверка Prisma после применения сообщает актуальную схему; сравнение живой базы со схемой даёт пустую миграцию. Число пользователей/разговоров/оценок/учебных заданий/калибровок осталось `18 / 99 / 97 / 11 / 4`.

На `http://localhost:4000` проверены 26 маршрутов после настоящего UI-входа, шесть ролей и 11 GET API-поверхностей. Dashboard и остальные проверенные разделы открываются без ошибки загрузки, Prisma-ошибок, 5xx и ошибок браузера. `/api/v1/health` отвечает HTTP 200, `status=ok`, `database=ok`. Метрики возвращаются в штатном Prometheus-формате; защищённые bearer API без токена возвращают ожидаемый 401.

Очередь фоновых заданий сообщает `degraded`: в старом демо-наборе намеренно присутствуют FAILED, RUNNING и QUEUED записи. Они не сбрасывались и не запускались ради изменения индикатора. Внешние уведомления, импорт, каталог и live-провайдеры не запускались.

## Методика и покрытие

Проверка включала отступы, собственные границы карточек и контролов, выравнивание текста, переносы, читаемость, мобильную компоновку, раскрытые формы и вкладки. DOM-измерения сочетались с просмотром снимков экрана: отсутствие горизонтальной прокрутки документа само по себе не доказывает, что вложенный блок ничего не обрезает.

- Основные ширины: **320, 390, 768, 1280, 1914 px**; верхняя панель дополнительно проверена на 1024, 1100 и 1279 px.
- Административные разделы: 208 случаев маршрут/ширина (80 URL-состояний), 111 дополнительных интерактивных состояний, 20 финальных проверок всех вкладок OTRS. Проверены все 15 основных административных страниц, существующие интеграции и задания, формы создания и редактирования, выборы источников, настройки оформления и представительские тёмные состояния.
- Обучение: 39 состояний администратора и оператора, создание без сохранения, поиск без результатов, очереди, последняя страница follow-up, новые категории и темы.
- Проверки/обратная связь: очередь и её срезы, две карточки разговора, точные фильтры, ИИ-предложения, workflow, обратная связь оператора, раскрытая апелляция и длинная непрерывная ссылка.
- Калибровка: четыре статуса сессий, матрица, консенсус, форма создания без отправки.
- Основной экран и отчёты: все три представления, пустая и заполненная выборки, верхняя панель и компактные меню, карточки графиков; вход и ожидание доступа на всех пяти ширинах.
- Инвентаризация исходников: 28 Next page entry points, 198 файлов в `components` с новым hook измерения ширины, 75 общих UI-файлов. Отложенный InputOTP не имеет действующего продуктового сценария.

Таблицы, полосы вкладок, примеры кода и длинные списки могут иметь собственную прокрутку. Скрытые элементы, закрытые порталы и screen-reader copy не считаются видимым переполнением. Проверки не заменяют серверную авторизацию и не изменяют деловые данные.

## Подтверждённые исправления

| Область | Проблема и результат |
| --- | --- |
| Верхняя панель | Кнопки перекрывались при 320/390/768 px без переполнения документа. Компактные профиль и пульс освобождают место; все кнопки раздельны, имена и функции сохранены. |
| Хлебные крошки и бейджи | Длинная цепочка расширяла 320 px документ до 343 px; риск-бейдж выходил из карточки. Ограничены собственными контейнерами, подписи переносятся или сокращаются с полной подсказкой. |
| Общие вкладки | Фиксированная высота одной строки не учитывала перенос. Список увеличивает высоту вместе со строками и не перекрывает панель. |
| Заголовки карточек | Минимальная ширина grid-текста вытесняла действия. Колонка допускает сжатие; длинные действия в узких коучинговых/административных карточках переходят под описание. |
| Обучение | Документ 415 px при viewport 390 px; текст задач сжимался до 33 px при 320 px. Исправлены сетка, график, полноширинные строки и положение действий, переносы категорий. |
| Обратная связь | Документ растягивался до 518 px; апелляция обрезалась внутри accordion. Устранены минимальные размеры, неуместное shrink-0 и двойные отступы. |
| Очередь и workflow | Счётчик фильтров налезал на подсказку; кнопка workflow выходила за внутренний отступ при 768 px. Исправлены переносы и число колонок. |
| Сообщения | Непрерывный URL обрезался внутри пузыря без прокрутки документа. Сообщение остаётся в колонке, текст может переноситься в любом месте длинного токена. |
| SSO, каналы и runtime | Длинные адреса и минимальные grid-колонки создавали переполнение вплоть до 554 px. Адреса и текст помещаются в карточки; таблицы сохраняют локальную прокрутку. |
| OTRS | Содержимое шириной 426 px обрезалось внутри 224 px блока; дополнительные маршруты и переключатели выходили за границы. Исправлены вкладки, fieldset, колонки, подписи и кнопки. |
| Формы оценки | Текст критерия превращался в узкую полоску возле редактирования. На мобильном название и действия занимают отдельные строки, сохраняются клавиатура и функции. |
| Select | Видимое `auto` и другие технические значения заменены соответствующими существующими русскими подписями через публичное `items`; отправляемые значения не изменены. |
| Графики | Переключатели больше не сжимают описание в узкую колонку. Геометрия SVG рассчитывается по ширине графика, чтобы подписи осей не уменьшались до нескольких пикселей; выбор точки использует ту же геометрию. |
| Рейтинги отчёта | Имя оператора практически исчезало между оценкой, дельтой и кнопкой. В узкой карточке имя и метрики занимают отдельные строки; полные подписи переносятся и остаются читаемыми. |

Для графиков отдельно проверены 15 комбинаций трёх представлений и пяти ширин. Фактический размер подписи через SVG CTM на 320 px вырос с 4,03 px до примерно 11 px. Ширина viewBox совпадает с шириной блока с погрешностью до 0,5 px; подсветка выбранной клавиатурой точки совпадает с SVG-точкой с погрешностью до 0,19 px. Измерение ширины и расчёт геометрии общие для визуального и интерактивного слоёв, повторный независимый расчёт удалён. Recharts сохранён.

## Регрессии и границы

Добавлены браузерные регрессии для административных форм, обучения, общих компонентов, обратной связи и адаптивной геометрии графиков. Их запускает штатный verify-DB workflow на отдельной `qc_app_demo_verify`; локальная `qc_app` не используется для seed или изменяющих тестов.

Локально прошли typecheck, production build, аудит зависимостей (0 уязвимостей) и 30 новых регрессий Chrome. JS-бюджеты проходят с неизменными baseline и лимитами: shared 324902 B, полная цепочка rich-chart 63410 / 71680 B. Итоговые результаты полного CI и других браузеров подтверждаются отдельно для опубликованного коммита.

Проверены существующие данные и перечисленные состояния. В локальной БД нет заполненных планов коучинга: их композиция проверена по исходникам и unit-фикстурам, без заявления о визуальной сертификации заполненного состояния. Полный набор произвольных пользовательских строк, пользовательские палитры, масштаб браузера и реальные ответы внешних сервисов не исчерпываются этим аудитом.

Снимки и подробные локальные журналы находятся в `/tmp/stemma-design-audit/`. Новые тесты остаются в репозитории. Итоговые результаты сборки, тестов, бюджетов и GitHub CI приводятся в сообщении о завершении.

Методика опирается на [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md), действующую дизайн-систему проекта и [подобранные UI-референсы](https://www.lazyweb.com/agentic-search/ad124b0c-6a05-4af9-8da1-d1158bbbaa7a). Референсы использовались для проверки компоновки; визуальное направление продукта не заменялось.
