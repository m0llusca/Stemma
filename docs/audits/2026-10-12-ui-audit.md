Recharts остаётся единственной непосредственно используемой библиотекой графиков. Прямые зависимости D3 не добавлены. Собственные SVG-оси, подписи, подсветки и обработчики выбора дополняют Recharts; это не утверждение, что каждый график реализован целиком через `LineChart` или `BarChart`.

## Состав компонентного слоя

- 190 файлов TS/TSX под `src/components`: 74 файла базового UI и 116 предметных/составных файлов.
- 59 из 74 UI-файлов достижимы из файлов входа App Router. Достижимость включает отложенные импорты; она не означает, что весь файл скачивается на каждой странице или что каждый его export используется.
- Основные предметные группы: navigation/auth, review/queue/workbench, reports/evidence/charts, dashboard, integrations/admin, calibration/coaching/feedback, operations.
- Общие обёртки: `PageShell`, `StatKpi`, `StatCard`, `EmptyState`, `StatusBadge`, `AdminDialog`, `useToast`, `ChartContainer`/`StaticChartContainer`.

## Выводы

1. **Компонентный стек уже унифицирован вокруг shadcn/Base UI.** Прямых импортов Radix в исходниках продукта нет; Radix присутствует транзитивно через cmdk. Его наличие в lockfile не означает второй самостоятельно поддерживаемый набор диалогов.
2. **shadcn — исходники компонентов, а не runtime-пакет компонентов.** Удалён уязвимый CLI `shadcn`, не используемый скриптами приложения. Его единственный сборочный импорт CSS сохранён как `src/app/shadcn-primitives.css` из 4.21.3 с MIT-лицензией. Это не удаление shadcn/ui из продукта. Для дальнейшего обновления registry-компонентов нужно отдельно проверять безопасность CLI; возвращать уязвимый пакет в общий dependency tree не следует.
3. **Графики приведены к Recharts.** Остаточные линии/столбцы собственных SVG-графиков переведены на публичные фигуры Recharts. Нулевые корзины сохраняют подписи и место на оси; фигура с нулевой высотой не рисуется. Прямых deep-import из внутренних `recharts/es6/*` нет.
4. **Исправлена граница UI и серверного доступа к данным.** Константы и парсер URL-фильтров вынесены из `review-repository` в чистый `lib/review/queue-filters.ts`. Клиентский тест запрещает импорт БД из URL-парсера. Палитра команд не должна загружать серверный репозиторий только ради фильтров.
5. **Базовый UI и предметные обёртки разделены.** `CommandDialog` отделён от cmdk-контента; для серверного sparkline есть отдельная клиентская граница Recharts. Нативные hidden inputs в формах и SVG-аннотации являются частью реализации, а не признаком ещё одной UI-библиотеки.

Аудит описывает реализацию и использование компонентов. Он не является визуальной приёмкой каждого экрана. Доступность и поведение проверяются браузерными сценариями; конкретные результаты — в [отчёте исправлений](2026-10-12-security-and-budgets.md).
