Design Improvement: Reports Subtabs

TL;DR

Главный шанс улучшения: сделать каждую вкладку отдельным рабочим режимом. Не просто разные данные в одинаковых карточках, а scoreboard для исполнения, incident cockpit для процесса и workbench для разрезов.

Current State

Improvement Ideas

1. Scoreboard для вкладки исполнения

Ранжированные списки должны читаться как операционный scoreboard: место, имя, оценка, дельта и короткий индикатор качества в одной строке.

Why this works: строки становятся сканируемыми по приоритету, а не выглядят как обычный список ссылок.

┌ Rank ┬ Operator              Score  Delta ┐
│  1   │ Линия доставки        78     -6    │
│      │ 14 проверок  ━━━━━━━━━━━      │
└──────┴───────────────────────────────┘

2. Incident cockpit для вкладки процесса

Процессная вкладка должна начинаться с блока эскалаций, похожего на status console: критические ошибки, переответы, апелляции.

Inspired by: status dashboards and incident management screens where color and layout express urgency before the user reads details.

┌ Контроль процесса ┬ Critical ┬ Reanswer ┬ Appeals ┐
│ brief             │ 1        │ 8        │ 6       │
└───────────────────┴──────────┴──────────┴─────────┘

3. Workbench для вкладки разрезов

Вместо стены одинаковых таблиц нужен левый индекс: критерии, норма, источники, люди, статусы. Он снижает перегрузку и дает быстрые якоря.

┌ Index ┐ ┌ Table grid                         ┐
│ 5     │ │ Блоки критериев │ Нормы проверок  │
│ links │ │ Источники       │ Операторы       │
└───────┘ └────────────────────────────────────┘

What's Working

Период, фильтры и вкладки уже собраны консистентно. Общий график качества больше не дублируется в под-разделах. Данные демо-режима достаточно богаты, чтобы показывать реальные различия между вкладками.
